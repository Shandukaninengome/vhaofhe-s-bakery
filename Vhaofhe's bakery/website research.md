# Vhaofhe's Bakery Website Research

## 1. Introduction

This research was completed to support the development of the Vhaofhe's Bakery website. The research focused on website structure, HTML, CSS, responsive design, forms, accessibility and website navigation.

The aim was to use simple and suitable web development techniques to create a website that is easy for customers to use.

---

## 2. Website Structure Research

A website should have a clear structure so that users can easily find the information they need.

For Vhaofhe's Bakery, the website was organised into five main pages:

- Home
- About Us
- Products
- Order / Enquiry
- Contact

The pages are connected using a navigation menu.

This structure makes it easier for visitors to move between the different sections of the website.

---

## 3. HTML Research

HTML5 is used to create the structure and content of a website.

HTML can be used to create:

- Headings
- Paragraphs
- Images
- Links
- Forms
- Buttons
- Navigation sections

For the Vhaofhe's Bakery website, HTML5 is used for the five website pages.

The website uses separate HTML files for each main page so that the content is organised clearly.

Source:

MDN Web Docs. Forms and buttons in HTML.

---

## 4. CSS Research

CSS is used to control the appearance and layout of a website.

CSS can be used to control:

- Colours
- Fonts
- Spacing
- Images
- Page layout
- Navigation
- Forms
- Responsive behaviour

For Vhaofhe's Bakery, CSS is stored in the css folder in a file called style.css.

Using one CSS file helps keep the design consistent across the website.

---

## 5. Responsive Design Research

Responsive web design allows a website to adapt to different screen sizes and devices.

A responsive website should work on:

- Desktop computers
- Laptops
- Tablets
- Smartphones

Responsive design can be achieved using flexible layouts, responsive images and CSS media queries.

The Vhaofhe's Bakery website uses responsive CSS so that the pages can be viewed on different screen sizes.

Source:

MDN Web Docs. Responsive Web Design.

https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design

## 6. Forms Research

Forms allow website visitors to enter and submit information.

A form can contain:

- Text fields
- Email fields
- Telephone fields
- Selection fields
- Message areas
- Submit buttons

The Vhaofhe's Bakery website includes an Order / Enquiry page where customers can provide information about their enquiry or order.

Forms should use clear labels and appropriate input fields so that users understand what information they need to provide.

Source:

MDN Web Docs. Forms and buttons in HTML.

https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_forms

---

## 7. Accessibility Research

Website accessibility means making a website easier for different users to access and understand.

Simple accessibility practices include:

- Using clear headings.
- Using descriptive link text.
- Adding alternative text to images.
- Using labels for form fields.
- Using appropriate HTML elements.

The Vhaofhe's Bakery website uses alternative text for images and clear headings and links where appropriate.

Source:

MDN Web Docs. HTML: A good basis for accessibility.

https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility/HTML

---

## 8. Image Research

Images are important for a bakery website because customers need to see the products.

The Vhaofhe's Bakery website uses images to display bakery products such as cakes, cupcakes, pastries, rolls and drinks.

Images should be placed in an organised images folder.

The images should also be sized appropriately so that they do not cause the page layout to become difficult to use.

---

## 9. Navigation Research

Navigation helps visitors move between the different pages of a website.

A navigation menu should be:

- Simple
- Clear
- Consistent
- Easy to find

The Vhaofhe's Bakery website uses the same basic navigation structure across its pages.

The navigation links connect the Home, About Us, Products, Order / Enquiry and Contact pages.

---

## 10. Contact and Social Media Research

A bakery website should make it easy for customers to contact the business.

The Contact page provides business contact information and other useful information for customers.

The website also provides Facebook and WhatsApp links so that visitors have additional ways to connect with the bakery.

Social-media links should use working links rather than empty placeholder links when the final website is submitted.

---

## 11. Browser Testing Research

Websites can display differently in different browsers.

The Vhaofhe's Bakery website should therefore be tested using:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

Testing should check:

- Navigation links
- Images
- Forms
- Google Maps
- Social-media links
- Page layout
- Responsive behaviour

---

## 12. Conclusion

The research helped guide the development of the Vhaofhe's Bakery website.

The research showed the importance of:

- Clear website structure
- HTML5
- CSS3
- Responsive design
- Simple navigation
- Usable forms
- Accessibility
- Organised images
- Contact information
- Social-media links
- Browser testing

These findings were applied to the Vhaofhe's Bakery website while keeping the design simple and easy to use.
